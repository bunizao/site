# buxx.me

Personal bio/portfolio website. Live at https://buxx.me.

## Tech Stack
- Astro
- React
- TypeScript
- TailwindCSS

## Development
```bash
pnpm install
pnpm dev
```

## Build
```bash
pnpm build
pnpm preview
```

## Environment Variables
```
GHOST_URL=https://your-ghost-site.com
GHOST_CONTENT_APIKEY=your_api_key_here
```
